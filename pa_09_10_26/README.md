Calculadora

Uma calculadora simples feita com HTML, CSS e JavaScript.

Funcionalidades
Somar, subtrair, multiplicar e dividir.
Usar números decimais.
Limpar e apagar números.
Usar o teclado do computador.
Como usar

Abra o arquivo index.html no navegador e comece a calcular.

Tecnologias
HTML
CSS
JavaScript
